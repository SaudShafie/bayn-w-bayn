# بين وبين 🎯
لعبة تخمين جماعية بالعربي (مستوحاة من فكرة Wavelength)، ٢٦٥ بطاقة أصلية في ٢١ تصنيف.

## أسهل طريقة (بدون نت ولا سيرفر)
افتح `index.html` بأي متصفح ← «تمرير الجوال» ← اكتبوا أسماءكم ← العبوا بجوال واحد تمررونه.

## النشر مجاناً على GitHub Pages
1. سوّ مستودع جديد على GitHub وارفع فيه ملفات هالمجلد (لازم `index.html` يكون بأول المستودع).
2. من المستودع: Settings ← Pages ← Source: «Deploy from a branch» ← Branch: `main` و `/ (root)` ← Save.
3. بعد دقيقة تقريباً تصير اللعبة على: `https://اسمك.github.io/اسم-المستودع/`

وضع «مضيف + جوالات» يشتغل على GitHub Pages بدون سيرفر: الجوالات تتصل بالتلفزيون مباشرة عن طريق PeerJS (يحتاج نت، ومو لازم تكونون على نفس الواي فاي).

## التلفزيون + الجوالات
1. افتح اللعبة على التلفزيون/اللابتوب ← «مضيف + جوالات» ← «افتح الغرفة».
2. كل واحد يمسح الـQR أو يفتح رابط `play.html` ويكتب الكود واسمه.

### تشغيل محلي بالسيرفر (اختياري)
إذا ما فيه نت بس فيه واي فاي: داخل المجلد شغّل `npm start` (يحتاج Node.js) وافتح `http://IP:3000/host` على التلفزيون و `http://IP:3000/play` على الجوالات.

## القواعد
الوسيط يشوف الطرفين والهدف السري ويكتب تلميح قصير (بدون أرقام وبدون كلمات البطاقة). الباقين يحطون الإبرة. المنتصف ٤، بعده ٣، بعده ٢، برا ٠. الوسيط ياخذ متوسط نقاط اللاعبين. الوسيط يتغير كل جولة.

## إضافات
- اختيار تصنيفات معينة أو الكل، وإضافة بطاقاتك الخاصة (تنحفظ في المتصفح).
- اللعبة تتذكر البطاقات اللي لعبتوها عشان ما تتكرر، وتحفظ أعلى النتائج.
- التدريب الفردي: الهدف يطلع لك ٣ ثواني وتحط الإبرة من ذاكرتك.
- البطاقات في `data.js` — كل بطاقة لازم تكون مقياس له طرفين متضادين وبينهم درجات.
